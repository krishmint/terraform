Terraform AWS Infrastructure - File Structure and Download Guide

To recreate this project locally, create the following directory structure and files:

terraform/
├── main.tf
├── variables.tf  
├── outputs.tf
├── backend.tf
├── terraform.tfvars
├── README.md
└── modules/
    ├── vpc/
    │   ├── main.tf
    │   ├── variables.tf
    │   └── outputs.tf
    ├── security_group/
    │   ├── main.tf
    │   ├── variables.tf
    │   └── outputs.tf
    ├── iam/
    │   ├── main.tf
    │   ├── variables.tf
    │   └── outputs.tf
    ├── autoscaling/
    │   ├── main.tf
    │   ├── variables.tf
    │   ├── outputs.tf
    │   └── user_data.sh
    └── waf/
        ├── main.tf
        ├── variables.tf
        └── outputs.tf

Instructions:
1. Create the directory structure above
2. Copy the content from each file in the project explorer
3. Paste into corresponding files in your local directory
4. Update backend.tf with your S3 bucket name
5. Customize terraform.tfvars for your environment
6. Run: terraform init && terraform plan && terraform apply

All files are available in the project explorer on the left side of this interface.
